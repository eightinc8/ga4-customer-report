===================================
 GA4レポート - スプレッドシート設定手順
===================================

【1. スプレッドシート作成】

新規Googleスプレッドシートを作成し、「顧客一覧」シートを用意。

ヘッダー行（1行目）:
  A1: 会社名
  B1: ログインID
  C1: GA4プロパティID
  D1: ステータス

データ行（2行目以降）:
  A2: A商事
  B2: a-shoji
  C2: 123456789    ← GA4管理画面の「プロパティID」
  D2: 有効

※ステータスが「有効」の顧客のみレポートが自動取得されます


【2. GASプロジェクト作成】

1. スプレッドシートのメニュー → 拡張機能 → Apps Script
2. Code.gs に gas/Code.gs の内容を貼り付け


【3. Google Analytics Data API を有効化】

1. Apps Script エディタ左メニュー → サービス → 「+」
2. 「Google Analytics Data API」を検索して追加
3. 識別子は「AnalyticsData」のまま


【4. スクリプトプロパティ設定】

Apps Script エディタ → プロジェクトの設定 → スクリプトプロパティ:

  SPREADSHEET_ID    → スプレッドシートのID（URLの /d/xxxxx/ の部分）
  VPS_API_URL       → https://ga4kanri.customer8.jp/api/reports/push
  VPS_API_KEY       → VPS側の .env に設定した GAS_API_KEY と同じ値


【5. GA4 プロパティIDの確認方法】

Google Analytics → 管理 → プロパティ設定 → プロパティID（数字9桁程度）


【6. トリガー設定】

1. Apps Script エディタ → トリガー（時計アイコン）
2. 「トリガーを追加」
3. 設定:
   - 実行する関数: weeklyReport
   - イベントのソース: 時間主導型
   - 時間ベースのトリガータイプ: 週ベースのタイマー
   - 曜日: 毎週月曜日
   - 時刻: 午前9時〜10時


【7. テスト実行】

1. Apps Script エディタで「testSingleCustomer」を選択して実行
2. 初回はGoogleアカウントの認証許可が必要
3. 実行ログで結果を確認


【8. 実行ログ確認】

スプレッドシートに「実行ログ」シートが自動作成され、
毎週の実行結果が記録されます。
